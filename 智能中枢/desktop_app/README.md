# 真实设备上位机

第一阶段不使用模拟器，也不要求用户在终端输入命令。双击项目根目录的 `外接大脑上位机.app`，会打开一个本地桌面窗口。

窗口提供：

- 左侧 JARVIS 动态能量球和微信式中文对话气泡；
- 本次运行期间持续复用的智能体会话；
- 允许前一条命令执行时继续发送后续命令；
- 每条命令独立显示执行完成、已排队、执行失败或执行超时；
- 右侧真实设备状态卡片墙；
- 录音豆的录音、TF 卡、Wi-Fi、MQTT 和当前文件状态；
- 点击设备卡片切换当前对话目标；
- 离线状态与最近一次历史状态的区分；
- 必要时自动启动本地 MQTT Broker 和中枢服务。
- 中枢服务和桥启动成功后，自动把 `bean_ye_1` 注册或更新到 RK3588；RK3588 重启、暂时离线或注册信息缺失时，会自动按指数退避重试。

上位机启动中枢时会同时启动 HTTP-MQTT 兼容桥，监听 `0.0.0.0:19700`，供 RK3588 固定式中枢通过 HTTP 控制当前 MQTT 录音豆。若检测到已有旧版中枢服务但桥尚未启动，会自动使用独立桥接进程补起，不要求用户打开终端。

当前文字解析是第一阶段规则版，支持“开始录音”“停止录音”“查询状态”“查看设备”。设备卡片只显示中枢真实注册的设备，不展示模拟器或规划中的虚拟设备。后续接入大模型时，保留上位机、中枢 API 和真实硬件协议不变。

## RK3588 注册配置

上位机默认使用当前联调地址：

- RK3588：`http://192.168.0.140:8095`
- RK3588 可访问的桥地址：`http://192.168.0.107:19700`

如果电脑或局域网地址变化，在启动上位机前设置环境变量，不要把 `127.0.0.1` 填入 RK3588 的设备注册信息：

```bash
export RK3588_BASE_URL="http://<RK3588地址>:8095"
export HUB_BRIDGE_PUBLIC_URL="http://<本机局域网地址>:19700"
```

还可以通过 `HUB_REGISTER_DEVICE_ID`、`HUB_REGISTER_DEVICE_NAME` 和 `HUB_REGISTER_DEVICE_CAPABILITIES` 覆盖默认设备注册信息。能力列表使用逗号分隔，例如 `record.start,record.stop,status.read`。
